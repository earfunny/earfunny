Membangun mesin AI offline.

Buat asisten AI yang berjalan di komputer sendiri dengan Ollama dan Python. Setelah model diunduh, kamu bisa mengobrol dengannya tanpa mengirim prompt ke layanan cloud.

oleh earfunny 8 menit membaca panduan pemula

Menjalankan AI sendiri terdengar rumit, tetapi kita tidak perlu melatih model dari nol. Cara yang lebih praktis adalah mengunduh model bahasa yang sudah dilatih, menjalankannya secara lokal, lalu menghubungkannya ke program kecil yang kita buat.

Dalam panduan ini kita memakai Ollama sebagai runtime dan model qwen2.5:3b sebagai contoh. Ollama menyediakan API lokal; Python mengirim pertanyaan ke API tersebut dan menampilkan jawaban model.

“Offline” dimulai setelah model tersedia di komputer.Instalasi dan unduhan model pertama kali memerlukan internet. Sesudah itu, contoh di sini membuat inferensi melalui server lokal Ollama—tanpa API key atau layanan AI cloud.

Yang dibutuhkan

  • Komputer Windows, macOS, atau Linux yang bisa memasang Ollama.
  • Ruang disk untuk model. Model 3B terkuantisasi berukuran beberapa gigabita; ukuran tepatnya dapat berubah.
  • RAM yang cukup untuk model dan aplikasi lain. 8 GB RAM atau lebih adalah titik awal yang lebih nyaman; model yang lebih besar memerlukan lebih banyak sumber daya.
  • Python 3 untuk menjalankan contoh program. Tidak wajib untuk mencoba model lewat terminal.

CPU dapat digunakan tanpa GPU khusus, tetapi kecepatannya bergantung pada perangkat. GPU yang didukung dapat membantu mempercepat proses, tetapi bukan syarat untuk mengikuti panduan ini.

1. Pasang Ollama

Unduh installer untuk sistem operasi kamu dari halaman unduhan Ollama, lalu jalankan installer. Setelah terpasang, buka terminal baru—PowerShell di Windows atau Terminal di macOS/Linux—dan periksa bahwa perintahnya tersedia:

PowerShell / Terminal
ollama --version

Ollama biasanya menjalankan layanan lokal yang dibutuhkan oleh perintah dan API-nya. Kalau perintah belum dikenali, tutup lalu buka terminal kembali; pastikan instalasi selesai sebelum mencoba lagi.

2. Unduh dan coba model

Ambil model selagi komputer masih terhubung ke internet. Tag qwen2.5:3b adalah contoh model kecil untuk memulai, bukan jaminan akan cocok untuk semua bahasa, perangkat, atau kebutuhan:

PowerShell / Terminal
ollama pull qwen2.5:3b
ollama run qwen2.5:3b

Setelah unduhan selesai, perintah kedua membuka percakapan di terminal. Coba bertanya, lalu ketik /bye untuk keluar. Daftar model yang sudah tersimpan bisa dilihat dengan:

PowerShell / Terminal
ollama list

Nama dan ketersediaan tag model dapat berubah. Bila contoh tag tidak ditemukan, pilih model teks yang tersedia di library Ollama, lalu gunakan tag yang sama saat mengunduh dan menjalankannya. Perhatikan ukuran model dan lisensinya.

3. Hubungkan ke Python

Dengan model sudah terunduh, buat file bernama asisten.py. Contoh berikut hanya memakai pustaka bawaan Python dan endpoint chat lokal Ollama:

asisten.py
import json
from urllib.request import Request, urlopen

MODEL = "qwen2.5:3b"

def tanya(prompt):
    payload = {
        "model": MODEL,
        "stream": False,
        "messages": [
            {
                "role": "system",
                "content": "Jawab dengan jelas dan ringkas dalam bahasa Indonesia.",
            },
            {"role": "user", "content": prompt},
        ],
    }
    request = Request(
        "http://localhost:11434/api/chat",
        data=json.dumps(payload).encode("utf-8"),
        headers={"Content-Type": "application/json"},
        method="POST",
    )

    with urlopen(request, timeout=120) as response:
        result = json.load(response)
    return result["message"]["content"]

while True:
    pertanyaan = input("Kamu (ketik 'keluar' untuk selesai): ")
    if pertanyaan.strip().lower() == "keluar":
        break
    if pertanyaan.strip():
        print(f"\nAI: {tanya(pertanyaan)}\n")

Simpan file, pastikan model tersedia, lalu jalankan:

PowerShell / Terminal
python asisten.py

Di beberapa instalasi Windows, perintah Python bisa bernama py; coba py asisten.py jika python tidak ditemukan. Program ini mengirim permintaan ke localhost, yaitu komputer kamu sendiri, bukan endpoint cloud.

4. Uji dalam keadaan offline

  1. Pastikan unduhan model sudah selesai dan ollama list menampilkan modelnya.
  2. Jalankan python asisten.py saat Ollama aktif, lalu coba pertanyaan sederhana.
  3. Putuskan koneksi internet dan ulangi percobaan. Jika model sudah tersedia dan layanan lokal berjalan, jawaban tetap dihasilkan di perangkat.

Jika komputer tidur atau Ollama ditutup, jalankan kembali Ollama sebelum membuka program. Aplikasi yang membutuhkan model ini juga harus mengarah ke API lokal, bukan mengirim permintaan ke layanan AI lain.

Privasi, keamanan, dan batasan

Dengan contoh ini, prompt dikirim ke proses Ollama di komputer yang sama. Itu mengurangi kebutuhan mengirim isi percakapan ke penyedia model cloud, tetapi bukan jaminan privasi untuk seluruh komputer. Aplikasi lain, plugin, malware, sinkronisasi file, atau konfigurasi jaringan yang berbeda tetap dapat mengakses data.

  • Jangan ubah layanan agar dapat diakses dari jaringan publik kecuali kamu paham autentikasi, firewall, dan pengamanan aksesnya.
  • Jangan menganggap jawaban model selalu benar. Periksa fakta penting, terutama untuk kesehatan, hukum, keuangan, dan keputusan berisiko.
  • Model lokal tidak otomatis memiliki informasi terbaru, akses web, atau kemampuan membuka dokumen. Fitur tambahan seperti pencarian dokumen lokal perlu dibangun secara terpisah.
  • Unduh model dari sumber tepercaya dan baca lisensinya sebelum dipakai atau dibagikan dalam produk.

Kalau belum berhasil

Perintah ollama tidak ditemukan

Pastikan installer selesai, buka terminal baru, lalu coba ollama --version. Jika masih gagal, ikuti petunjuk instalasi untuk sistem operasi kamu.

Python mendapat koneksi ditolak

Pastikan Ollama sudah berjalan dan model pernah berhasil diunduh. Periksa nama model di ollama list; nilai MODEL di script harus cocok dengan tag yang tersedia.

Jawaban lambat atau komputer kehabisan memori

Coba model yang lebih kecil atau tutup aplikasi lain. Model kecil juga memiliki kemampuan dan kualitas jawaban yang berbeda—ukuran lebih besar bukan selalu pilihan terbaik untuk perangkat terbatas.

Langkah berikutnya

Sekarang kamu punya dasar sebuah asisten AI lokal: runtime, model, dan program kecil yang menghubungkan keduanya. Dari sini, kamu bisa menambahkan riwayat percakapan, antarmuka web lokal, atau pencarian atas dokumen milik sendiri. Mulai dari versi sederhana, uji privasi dan kinerjanya, lalu kembangkan sesuai kebutuhan.
